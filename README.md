# Playday UI
This is the repository for the front end of the playday application, it uses DVUI as the framework for the UI
This is the main entrypoint for the playday application

## Building
just run `zig build` and `zig-out/bin/ui` will be created which is the binary you can run

## Dependencies

- playday-api (by default should be at the same directory as the ui directory and be called "api", can be changed in build.zig.zon)
